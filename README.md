# FlowDock

FlowDock is an open-source activity layer for macOS. It turns the notch—or the top edge of a non-notch display—into a calm home for music, system feedback, calendar context, files, and other timely activities.

FlowDock began as a fork of [BoringNotch](https://github.com/TheBoredTeam/boring.notch) and is being rebuilt around a distinct product and interaction model. See [ROADMAP.md](ROADMAP.md) for current direction and progress.

## Status

FlowDock is in active development. The inherited feature set is available, but the FlowDock experience and release process are still being established.

## Requirements

- macOS 14 Sonoma or later
- Apple Silicon or Intel Mac
- macOS 15.6 or later and Xcode 26 or later to build from source

## Build from source

```sh
git clone https://github.com/arnavbonigala/FlowDock.git
cd FlowDock
open FlowDock.xcodeproj
```

Select the `FlowDock` scheme in Xcode, then build and run.
