What appears

MusicPlayback, source selection, queues, lyrics, and capability-aware controls.
System feedbackVolume, brightness, keyboard backlight, and microphone, without displacing the native controls.
Battery and devicesCharging, Bluetooth and headphone connection, and device status.
CalendarEvents, reminders, meeting actions, countdowns, and timers.
NotificationsGrouped, with actions where macOS permits.
File shelfDrag files to the top edge, then preview, compress, convert, remove backgrounds, AirDrop, or share.

Opening it the first time

FlowDock ships without an Apple Developer ID, so macOS reports on first launch that it cannot check the app for malicious software. That is what an unnotarized build looks like — the release is built by a workflow anyone can read, from a tag anyone can rebuild.

  1. Try to open FlowDock. Dismiss the warning.
  2. System Settings → Privacy & Security, scroll to Security. A line names FlowDock. Click Open Anyway.
  3. Confirm. Every later launch is normal.

Or clear the flag yourself: xattr -d com.apple.quarantine /Applications/FlowDock.app

Updates

FlowDock updates itself. It reads a signed feed and installs what you approve; nothing else is downloaded, and there is no account and no analytics.
